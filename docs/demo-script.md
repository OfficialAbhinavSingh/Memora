# Five-Minute Demo Script

## 0:00-0:30 · Open With The Problem

Memora is a Persistent Context Engine for autonomous SRE. Traditional
observability stores telemetry, but it does not preserve operational reasoning.
Memora forms incident memory during ingestion and reconstructs evidence-backed
context at incident time.

## 0:30-1:10 · Benchmark Results

Open the frontend Benchmark Results tab.

Say:

- This page reads `web/public/benchmark-report.json`.
- The benchmark is generated by the official P-02 harness, not mocked in the UI.
- Current public result: recall@5 1.0, remediation accuracy 1.0, p95 latency far
  under the 2 second fast-mode budget.

## 1:10-2:00 · Incident Workspace

Open Incident Workspace and click Reconstruct Context.

Show:

- related events
- causal chain
- similar incident
- suggested remediation
- confidence and explain text

Say:

- The output is a structured `Context`, not free-text search.
- It matches the required benchmark shape: related events, causal chain, similar
  past incidents, suggested remediations, confidence, and explain.

## 2:00-2:45 · Topology Drift

Open Similar Incidents and Topology Aliases.

Show:

- `payments-svc -> billing-svc`
- same lineage after rename
- behavior-first ranking scores: match, shape, lineage, temporal, fallback

Say:

- A string-matching baseline fails after renames.
- Memora resolves stored historical canonicals through the live alias graph.
- Similarity is based on operational shape, not raw service names.

## 2:45-3:30 · Causal Chain

Open Causal Chain.

Show:

- deploy root cause
- latency spike
- upstream timeout
- rollback recommendation

Say:

- Edges preserve evidence labels, confidence, and ordering proof.
- The operator can inspect why the engine believes the causal chain exists.

## 3:30-4:20 · Remediation Learning

Open Remediations.

Show:

- rollback recommendation
- worked/failed/unsure feedback controls
- historical basis

Say:

- Worked remediations reinforce future suggestions.
- Failed remediations reduce confidence.
- Targets are remapped across service renames when lineage proves equivalence.

## 4:20-5:00 · Submission Readiness

Show `SUBMISSION.md`.

Say:

- Benchmark adapter is pure Python stdlib with no external egress.
- Judges can run `adapters.memora:Engine` in the official harness.
- Docker and runner scripts reproduce local checks and report generation.
- Hidden L3 is not distributed, so we added local adversarial regressions for
  chained renames, dependency drift, wrong root cause, and failed remediation.
